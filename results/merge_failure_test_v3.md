## Arms and design choices

1. Every arm is the converged Model Soup run with exactly one change (its flags in the manifest): the same start network, seed 111, contrastive settings (K 8, beta 0.1, margin 0.01, clip 1.0, lr 3e-4, 20 environments), instance and preference streams, validation and checkpoint selection, and the same stopping rule. None of the changes draws random numbers, so every random stream is that of the Model Soup run.
2. Shrink and perturb (Ash & Adams, NeurIPS 2020, Section 4): theta <- 0.3 theta + 0.0001 theta_fresh, where theta_fresh is the freshly initialised network of seed 111 (the From-scratch initialisation). The paper adds noise 'by adding parameters from a scaled, randomly-initialized network'; 0.3 and 0.0001 are its values for the pre-training-then-fine-tuning case (Section 4.2, Figure 9). Every parameter is shrunk, including the critic, which the contrastive objective never uses. The contrastive reference is the shrunk-and-perturbed network (the network fine-tuning starts from).
3. No anchor: the loss -log sigmoid(beta (l_better - l_worse)), the DPO loss with the reference log-probabilities set to zero. The start network is the Model Soup start, so its update-0 validation HV equals Model Soup's.
4. Random preference input: the preference-input columns of the first actor and critic layers keep the fresh seed-111 values (as in From scratch) instead of zero; every other weight is the merge's.
5. Part A uses no training: each network is built by train.py's own code with the arm's flags (same seed and transfer), measured on the validation split (all instances, the 15 validation preferences), and saved (starts/). The gradient is one contrastive gradient on the run's first batch (same instances and preferences for every network; schedules sampled from the network), before clipping; the weights are discarded afterwards.
6. Near-inactive unit: |activation| <= 0.01 on at least 99% of the entries of the validation batch (every state of the greedy validation rollouts, unfinished schedules only; attention-block outputs are ELU, actor hidden layers tanh). Saturated tanh unit: |activation| >= 0.99 on at least 99% of those entries.
7. Closing the gap: an arm closes the gap if its evaluation HV is at least From scratch's converged evaluation HV; otherwise the share closed is (arm - Model Soup) / (From scratch - Model Soup) on evaluation HV.
8. Wall-clock: same machine and --jobs 3 for all runs. From scratch was continued from its fixed-budget run, so its wall-clock includes that part; Model Soup and the new arms count from zero.
